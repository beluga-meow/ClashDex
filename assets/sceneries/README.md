# Sceneries

Drop scenery artwork in this folder and the Sceneries tab uses it automatically.

## File name

The scenery name, lower-case, words joined by `-`:

```
assets/sceneries/<scenery-name>.<ext>
```

Examples: `year-of-the-snake.webp`, `clash-of-dragons.png`, `snow-day.jpg`,
`pirate-cove.webp`, `royal-arena.webp`.

Accepted extensions, tried in this order: `.webp`, `.png`, `.jpg`, `.jpeg`, `.svg`.
A landscape picture around 800×450 looks best.

## Without a file

The card keeps its coloured gradient and icon, so nothing ever shows a broken
image.
