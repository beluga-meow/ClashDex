# Equipment icons

Drop an equipment icon in this folder and it replaces the emoji on that card.

## File name

The equipment name, lower-case, words joined by `-`:

```
assets/equipment/<equipment-name>.<ext>
```

Examples: `barbarian-puppet.webp`, `giant-gauntlet.png`, `eternal-tome.webp`,
`seeking-shield.svg`.

Accepted extensions, tried in this order: `.webp`, `.png`, `.jpg`, `.jpeg`, `.svg`.
Square images (64×64 to 128×128) look best because they sit in a 44 px tile.

## Without a file

The card keeps its emoji icon, so nothing ever shows a broken image.
