Draw it, then plan it

Attack Planner

Place the defences you can see, then read which army on file fits the layout.

Live tool

Plan the hit before the first troop lands

The planner is live: mark defences on a 12×12 grid, drop a screenshot of the base behind it, set the enemy Town Hall, and PekkaDex ranks the armies on file that suit the counts.

  1. 1Draw the base. Tap a defence, then tap the square it sits on.
  2. 2Read the counts. See how many defences can hit air or ground.
  3. 3Pick the army. Compare the ranked compositions and their TH range.
Open the Attack Planner Manual · no image AI

The score counts which defences can hit air or ground. It does not read the screenshot or know levels, walls or defending heroes.
