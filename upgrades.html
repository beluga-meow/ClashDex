PLAN THE GRIND

Village Tools

Two tools that work on numbers you type in yourself. PekkaDex does not ship Town Hall cost or time tables, so nothing here is guessed — and nothing leaves your browser: both tools save to this device only.

CALCULATOR

How long to max

Your numbers only

Add every upgrade that is left, then set your builders and any boosts. Builder work is shared between builders; the Laboratory and anything in Other queue run in parallel with the builders, so the finish time is the slowest of the three.

Longest single builder upgrade (optional)

The example button fills clearly labelled sample numbers so you can see how the maths works. Replace them with your own before trusting the result.

TRACKER

Upgrade Tracker

Saved on this device

Add what you have queued or running, and the planner draws one lane per builder plus a laboratory lane. Times are counted from this device's clock, so a phone whose clock is wrong will show wrong countdowns.

Duration

Planner

Queued items are placed on the builder lane that frees up first. Nothing is sent to the game — this is a drawing of your own plan.

Backup

“Running now” starts the countdown immediately, so enter the time that is left rather than the full upgrade time.

Notification alerts only fire while this page is open in a tab. Nothing runs in the background after you close it.
